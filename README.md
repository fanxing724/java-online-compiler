# 番星 Java 在线编译器

基于 [fanxing724/c-online-compiler](https://github.com/fanxing724/c-online-compiler) 的独立 Java 在线编译器项目。

## 项目状态

仓库已初始化，Java 版本开发暂缓。当前仓库仅包含项目说明与开源协议，尚无可运行的 Java 编译器。

后续计划沿用原项目的编辑器界面与 Judge0 编译流程，支持 Java 代码编辑、编译运行、标准输入和源码下载。

## 开源协议

沿用原项目的 **Academic Free License v3.0（AFL-3.0）**，完整条款见 [LICENSE](LICENSE)。

本仓库为原项目的 Java 版本衍生项目；初始化阶段尚未发布改编后的程序代码。
